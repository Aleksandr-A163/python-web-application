# Телефонный справочник

Консольный телефонный справочник на Python, построенный на классах по паттерну MVC.
Контакты хранятся в JSON-файле `contacts.json`.

## Возможности

- открыть и сохранить файл контактов;
- показать все контакты;
- создать, найти, изменить и удалить контакт;
- автоматически сохранять даты создания и последнего изменения контакта;
- группировать отсортированные контакты по первой букве имени;
- создавать произвольное количество тестовых контактов;
- ускорять повторный поиск с помощью кэша;
- предложить сохранить несохранённые изменения перед выходом;
- обработать ошибки ввода, поиска контакта, чтения и записи файла.

## Архитектура

- `model.py` — классы `Contact`, `PhoneBook`, `FileReader`, `FileWriter`;
- `generator.py` — класс `ContactGenerator` для тестовых данных;
- `view.py` — класс `ConsoleView`, отвечающий за ввод и вывод;
- `controller.py` — класс `PhoneBookController`, связывающий модель и представление;
- `exceptions.py` — иерархия пользовательских исключений;
- `main.py` — сборка приложения и точка входа;
- `test_phonebook.py` — модульные тесты модели и файлового слоя.

Модель не зависит от консоли: она возвращает данные или выбрасывает собственные
исключения. Контроллер обрабатывает эти исключения и передаёт понятные сообщения
представлению.

## Использование стандартной библиотеки

- `datetime` хранит даты создания и изменения контакта. В JSON даты записываются
  в ISO-формате; старые записи без этих полей загружаются автоматически;
- `itertools.groupby` группирует предварительно отсортированные контакты по
  первой букве имени;
- `random.Random` создаёт тестовые контакты, телефоны и коды подтверждения.
  Передача одинакового `seed` делает генерацию воспроизводимой;
- `functools.lru_cache` кэширует повторные поисковые запросы. Кэш очищается при
  добавлении, изменении, удалении и полной замене контактов.

## Аннотации типов

Параметры и возвращаемые значения функций снабжены аннотациями типов. Для
коллекций используются параметризованные типы (`list[Contact]`,
`tuple[Contact, ...]`), для функций обратного вызова — `Callable`, а сложные
структуры вынесены в алиасы `ContactData` и `ContactGroups`. Аннотации помогают
IDE и статическим анализаторам находить ошибки до запуска программы.

## Новые команды меню

- `8` — показать контакты, сгруппированные по первой букве имени;
- `9` — создать указанное количество случайных тестовых контактов;
- `10` — выйти из приложения.
