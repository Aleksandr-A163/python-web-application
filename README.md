# Телефонный справочник

Консольный телефонный справочник на Python, построенный на классах по паттерну MVC.
Контакты хранятся в JSON-файле `contacts.json`.

## Возможности

- открыть и сохранить файл контактов;
- показать все контакты;
- создать, найти, изменить и удалить контакт;
- предложить сохранить несохранённые изменения перед выходом;
- обработать ошибки ввода, поиска контакта, чтения и записи файла.

## Архитектура

- `model.py` — классы `Contact`, `PhoneBook`, `FileReader`, `FileWriter`;
- `view.py` — класс `ConsoleView`, отвечающий за ввод и вывод;
- `controller.py` — класс `PhoneBookController`, связывающий модель и представление;
- `exceptions.py` — иерархия пользовательских исключений;
- `main.py` — сборка приложения и точка входа;
- `test_phonebook.py` — модульные тесты модели и файлового слоя.

Модель не зависит от консоли: она возвращает данные или выбрасывает собственные
исключения. Контроллер обрабатывает эти исключения и передаёт понятные сообщения
представлению.

## Запуск

```bash
python main.py
```

## Проверка тестов

```bash
python -m unittest -v
```
