# Телефонный справочник

Простой консольный справочник на Python. Контакты хранятся в файле `contacts.json`.

## Возможности

- открыть файл с контактами;
- сохранить файл;
- показать все контакты;
- создать контакт;
- найти контакт по ID, имени, телефону или комментарию;
- изменить контакт;
- удалить контакт;
- выйти из программы;
- предложить сохранить изменения перед выходом.

## Структура проекта

- `contacts.py` - класс контакта;
- `storage.py` - загрузка и сохранение JSON-файла;
- `phonebook.py` - логика работы со справочником;
- `console_app.py` - консольное меню и ввод пользователя;
- `main.py` - точка входа;
- `test_phonebook.py` - тесты основной логики.

## Запуск

```bash
python main.py
```

## Проверка тестов

```bash
python -m unittest
```

## Почему JSON

JSON хорошо подходит для этого задания: контакт удобно хранить как словарь с полями
`id`, `name`, `phone`, `comment`, а список контактов легко загружать и сохранять.
